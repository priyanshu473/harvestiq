# HarvestIQ

AI-powered crop selling assistant — a premium SaaS-style dashboard concept for Indian farmers,
combining mandi prices, weather, cold storage and transport data into a single AI recommendation.

This is a **frontend-only** demo. All data (mandi prices, weather, AI predictions) is generated by a
deterministic dummy API in `src/services/api.js` — no backend or network calls are required.

## Tech Stack

- React 19 + Vite
- Tailwind CSS (custom design system: glassmorphism, gradient borders, contour textures)
- Framer Motion (page transitions, micro-interactions, animated counters)
- React Router v6 (with lazy-loaded routes / code splitting)
- React Hook Form (validated, floating-label forms)
- Recharts (bar / line / area / pie charts)
- Lucide React (icons)
- Context API (theme, toasts, analysis state — no Redux needed)

## Getting Started

```bash
npm install
npm run dev
```

Then open the printed local URL (usually `http://localhost:5173`).

## Project Structure

```
src/
  assets/            static assets
  components/
    animations/       FadeIn, AnimatedCounter
    cards/             StatCard, FloatingCard
    charts/            Recharts wrappers (bar/line/area/pie)
    common/             Button, Card, Input, Select, Badge, Skeleton, Toast, etc.
    dashboard/          (dashboard-only composites live in pages/Dashboard.jsx)
    features/           Home page feature grid
    forms/              AnalyzerForm (React Hook Form)
    hero/               Home page hero section
    layout/             Navbar, Sidebar, Footer, Layout, DashboardLayout
    results/            ResultSummary, PriceTable, AIRecommendation
    workflow/           Animated timeline
  context/            ThemeContext, ToastContext, AppContext
  data/               dummyData.js — crops, mandis, states, districts, features
  hooks/              useCountUp, useInView
  pages/              Home, Analyzer, AnalyzerResult, Dashboard, History, Settings, About, Contact, NotFound
  services/           api.js — dummy API layer (seeded-random, deterministic per input)
  styles/             index.css — Tailwind layers + design tokens
  utils/              helpers.js
  App.jsx
  main.jsx
```

## Design System

| Token      | Value      |
|------------|------------|
| Primary    | `#16A34A`  |
| Secondary  | `#10B981`  |
| Accent     | `#3B82F6`  |
| Warning    | `#F59E0B`  |
| Danger     | `#EF4444`  |

Typography: **Space Grotesk** (display), **Inter** (body), **IBM Plex Mono** (numeric/price data).

Dark mode is class-based (`darkMode: 'class'` in Tailwind) and toggled via the navbar sun/moon icon;
preference is persisted to `localStorage`.

## Notes

- All history and bookmarks persist to `localStorage` — clear your browser storage to reset.
- The floating chat button is a UI demo only; it does not call a real LLM.
- Export PDF / Export Excel / Share buttons show toast confirmations (demo only, no real file generated).
